# PolicyPulse: Public Sentiment Analysis Web App

# Abstract
In today’s digital governance era, understanding public opinion in real-time is
crucial for evaluating the impact of government schemes and policies. Social
media platforms, particularly Twitter, offer rich insights into citizens’ sentiments.
This project aims to develop an AI-powered web application that analyzes
the sentiment of public comments related to government schemes using
natural language processing.The system leverages a logistic regression model
trained on labeled Twitter data to classify sentiments as Positive, Neutral, or
Negative. Text preprocessing includes noise removal, stopword filtering, and
TF-IDF vectorization to convert raw text into feature vectors suitable for machine
learning.A dataset of public tweets is used for evaluation, and sample or
custom input is passed through the trained model via a Streamlit web interface.
Predictions are displayed with contextual cards and confidence indicators.The
application is expected to correctly identify sentiments with high accuracy, providing
real-time insights into public perception and possible pain points in policy
implementation.The system offers an intuitive UI, customizable input, modelbacked
predictions, and optional confidence scores. It also supports background
styling to enhance visual presentation.Policy analysts, government departments,
researchers, and journalists can benefit by using the tool to track and understand
citizen sentiment efficiently and at scale.The proposed solution bridges the
gap between citizen voices and policy evaluation, enabling data-driven decisionmaking
through real-time sentiment monitoring.
